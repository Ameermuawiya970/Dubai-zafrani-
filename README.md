## 🚀 GitHub Pages پر ایکٹو (Live) کرنے کا طریقہ (Urdu Instructions)

اگر آپ اس پروجیکٹ کو اپنے GitHub اکاؤنٹ کے ذریعے بالکل مفت انٹرنیٹ پر لائیو کرنا چاہتے ہیں تو درج ذیل آسان مراحل پر عمل کریں:

### مرحلہ 1: نیا ریپوزیٹری بنائیں (Create Repository)
1. اپنے [GitHub](https://github.com/) اکاؤنٹ میں لاگ ان کریں۔
2. اوپر دائیں کونے میں **"+"** کے بٹن پر کلک کر کے **"New repository"** منتخب کریں۔
3. ریپوزیٹری کا نام درج کریں (مثلاً: `dubai-zafrani-cream`)۔
4. اسے **Public** رکھیں اور **"Create repository"** پر کلک کریں۔

### مرحلہ 2: فائلیں اپ لوڈ کریں (Upload Files)
اس پروجیکٹ کی تمام فائلیں اپنے کمپیوٹر سے ریپوزیٹری میں اپ لوڈ کریں:
* `index.html` (مین ویب پیج)
* `style.css` (اسٹائلنگ اور ڈیزائن)
* `script.js` (آرڈر فارم اور انٹرایکشنز)
* `assets/product.png` (پروڈکٹ بیک اپ تصویر)
* `README.md` (رہنما فائل)

> **طریقہ:** ریپوزیٹری کے صفحہ پر **"Add file"** > **"Upload files"** پر کلک کر کے تمام فائلیں ڈریگ اینڈ ڈراپ کریں اور نیچے **"Commit changes"** کا بٹن دبائیں۔

### مرحلہ 3: GitHub Pages آن کریں (Enable GitHub Pages)
1. اپنی ریپوزیٹری کے اوپر موجود **"Settings"** (سیٹنگز) ٹیب پر کلک کریں۔
2. بائیں جانب مینو میں **"Pages"** کے آپشن پر کلک کریں۔
3. **"Build and deployment"** کے تحت **Source** میں **"Deploy from a branch"** منتخب کریں۔
4. **Branch** والے ڈراپ ڈاؤن مینو میں **`main`** (یا `master`) منتخب کریں اور فولڈر میں **`/(root)`** منتخب رہنے دیں۔
5. ساتھ موجود **"Save"** کا بٹن دبا دیں۔

### مرحلہ 4: مبارک ہو! آپ کی ویب سائٹ لائیو ہے
* 1 سے 2 منٹ انتظار کریں۔ صفحہ کو ریفریش کریں۔
